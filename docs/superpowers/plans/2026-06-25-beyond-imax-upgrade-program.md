# Beyond-IMAX Elite Upgrade Program

**Goal:** Raise NeoProCamX video + color quality to elite / cinema tier across all three
surfaces (preview, record, NPV10 master) with **no downgrades** to any existing feature.
"Beyond IMAX" = maximize per-frame information density (multi-frame fusion, 12-bit RAW,
all-intra 10-bit, AI super-res, motion-compensated temporal) — the sensor/optics floor is
physical and unchanged.

**Branch:** `checkpoint/elite-color-stability`
**Baseline:** CP00 = commit `3f66245` — 537 suites / 3115 tests / 0 failures.
**Mechanism:** one scoped git commit per checkpoint after build + tests green. High-risk
live-path changes gate on a golden/characterization test existing first (Phase 0).
**Device:** vivo I2405 / Adreno, Android 16 (owner-side on-device validation per checkpoint).
Build: `JAVA_HOME=".../Android Studio/jbr" ./gradlew :app:testDebugUnitTest`; native:
`:app:externalNativeBuildDebug -Pandroid.ndkPath=".../ndk/29.0.14206865"`.

## Headline finding (audit, 2026-06-25)
Most elite algorithms are **built but dormant / fed dummy or hardcoded inputs**. Activation +
correct wiring is the dominant lever, not new code:
- MFSR dispatched but bound to **dummy textures** (noise=0) → no-op.
- cinema-debayer / demosaic shaders **never compiled** → RAW runs through the YUV chain.
- SNCE computes a 23-float scene-brain every frame, **uploads none to the GPU**; IMU pitch &
  scene-change hardwired to 0.
- HDR live tone map is **SDR-referred** (clamps highlights ~0.92); dual-gain/photon/knee fusion
  shaders dormant.
- Gyro EIS **fabricated from optical flow**; real 1024-deep gyro/OIS ring buffer never reaches GPU.
- Quality gates check **hardcoded/heuristic** numbers, not real pixels.
- NPV10 master uses a **synthetic sin/cos "optical flow"** → not motion-equivalent to live.
